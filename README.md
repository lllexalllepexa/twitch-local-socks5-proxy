# Twitch Local SOCKS5 Proxy 🚀

Легковесное браузерное расширение (Manifest V3) для **Google Chrome** и **Mozilla Firefox**, которое решает проблему зависания, бесконечной буферизации или блокировки стримов на Twitch через локальный SOCKS5-прокси (Throne, Sing-Box, Xray, V2Ray и др.).

---

## 💡 Принцип работы

При открытии стрима расширение кратковременно (на **3 секунды**) перенаправляет сетевые запросы через ваш локальный SOCKS5-прокси:

```
Браузер ──► Локальный SOCKS5 (127.0.0.1:2080) ──► Прокси-клиент (Throne, Sing-Box, Xray, VPN и др.) ──► Twitch API
                                                                                                              │
                                          (спустя 3 секунды прокси отключается)                               ▼
Браузер ────────────────────────────────── Direct (видеопоток напрямую) ──────────────────────────► CDN Twitch
```

### Зачем это нужно?
* **Мгновенный старт стрима**: Плеер Twitch успевает беспрепятственно загрузить метаданные, манифест HLS (`usher.ttvnw.net`) и авторизацию (`gql.twitch.tv`) через прокси.
* **Экономия трафика и максимальная скорость**: Через 3 секунды прокси автоматически выключается, и сам тяжёлый видеопоток идёт напрямую от ближайших CDN Twitch. Это не расходует трафик / лимиты вашего VPN или прокси и исключает буферизацию из-за ограничений скорости внешнего канала.
* **Без черных экранов**: Перехват происходит мгновенно на уровне `webNavigation` ещё до старта рендеринга страницы.

## ⚙️ Настройка порта прокси

По умолчанию расширение настроено на адрес:
**`127.0.0.1:2080`**

Если ваш локальный клиент (Sing-Box, Xray, Throne и т.д.) слушает другой порт (например, `1080`, `2081`, `10808`):
1. Откройте файл `background.js` в папке нужного браузера (`chrome/background.js` или `firefox/background.js`).
2. Измените значение константы на 2-й строке:
   ```javascript
   const SOCKS_HOST = "127.0.0.1";
   const SOCKS_PORT = 2080; // Укажите ваш порт
   ```
3. Перезагрузите расширение в браузере.

## 📦 Установка

### Google Chrome / Chromium / Edge / Brave / Opera

1. Склонируйте репозиторий или скачайте его архивом:
   ```bash
   git clone https://github.com/lllexalllepexa/twitch-local-socks5-proxy.git
   ```
2. Откройте страницу управления расширениями:
   * Chrome: `chrome://extensions/`
   * Edge: `edge://extensions/`
   * Brave: `brave://extensions/`
3. В правом верхнем углу включите тумблер **«Режим разработчика»** (*Developer mode*).
4. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*).
5. Выберите папку **`chrome`** из скачанного репозитория.
6. Готово! В списке расширений появится **Twitch Local SOCKS5 Proxy**.

---

### Mozilla Firefox / Zen Browser / LibreWolf

В Firefox реализована поддержка специального API **`browser.proxy.onRequest`**. Расширение изолированно проксирует только запросы к Twitch и **не конфликтует с FoxyProxy** или другими системными прокси!

#### Вариант A. Временная установка (для быстрой проверки)
1. В адресной строке Firefox перейдите по адресу:
   `about:debugging#/runtime/this-firefox`
2. Нажмите кнопку **«Загрузить временное дополнение...»** (*Load Temporary Add-on...*).
3. Перейдите в папку **`firefox`** и выберите файл **`manifest.json`**.
4. Расширение сразу начнёт работать (действует до перезапуска браузера).

#### Вариант B. Постоянная установка через бесплатную подпись Mozilla (Рекомендуется для обычного Firefox)
*Политика Mozilla требует цифровой подписи для постоянных расширений в стабильных версиях Firefox. Mozilla подписывает личные дополнения автоматически и бесплатно за 2 минуты:*
1. Упакуйте содержимое папки `firefox` (файлы `manifest.json`, `background.js`, `popup.html`, `popup.js`, `icon128.png`) в zip-архив и смените расширение на `.xpi` (или `.zip`).
2. Перейдите на портал разработчиков [addons.mozilla.org/developers](https://addons.mozilla.org/developers/) и авторизуйтесь под Firefox Account.
3. Нажмите **«Отправить новое дополнение»** (*Submit a New Add-on*) ➔ выберите вариант **«На вашем собственном сайте (Unlisted)»**.
4. Загрузите ваш архив. Робот Mozilla проверит его и выдаст подписанный `.xpi`.
5. Перетащите скачанный `.xpi` в окно Firefox — дополнение установится навсегда.

#### Вариант C. Для Firefox Developer Edition / Nightly / Zen Browser
1. Откройте `about:config` и установите параметр:
   `xpinstall.signatures.required` ➔ **`false`**
2. Откройте `about:addons` ➔ нажмите на значок шестерёнки ⚙️ ➔ **«Установить дополнение из файла...»** и выберите упакованный `.xpi` или `manifest.json`.

## 🎯 Использование

* При открытии любого канала (например, `https://www.twitch.tv/shroud`) на значке расширения на 3 секунды загорится желтый бейдж **`ON`**.
* В этот момент видеоплеер инициализируется и начинает показ стрима без буферизации.
* Через 3 секунды бейдж гаснет, прокси отключается, а стрим продолжает воспроизводиться напрямую.
* Вы можете в любой момент временно выключить расширение, нажав на его иконку и выбрав **«ВЫКЛЮЧЕНО»**.
