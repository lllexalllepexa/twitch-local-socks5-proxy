## Twitch - tg - proxy
Chrome MV3 расширение, которое временно включает локальный HTTP/SOCKS proxy при открытии Twitch-стрима.

Принцип работы

Chrome → локальный HTTP/SOCKS proxy → sing-box/Xray/Throne → VLESS

Расширение на короткое время включает локальный proxy для инициализации Twitch-стрима, после чего proxy автоматически отключается.

Для добавления в любое другое приложение(например в тг), указываем http/socks локальный прокси

По дефолту это 127.0.0.1:1080

В файле 127.0.0.1:2080
